# מעקב משקל, רווחה והרגלים - גרסה 1

אפליקציית ווב אישית פשוטה בעברית לניהול מעקב יומי, עם עיצוב מודרני, רגוע וידידותי לשימוש יומיומי.

## מבנה קבצים

- `index.html` - מבנה כל המסכים (דשבורד, צ'ק-אין בוקר/ערב, ניתוח, צ'אטים), כולל ניווט ראשי, כפתור צ'אט צף (floating) ורכיבי טופס מעוצבים.
- `styles.css` - שכבת עיצוב מלאה: RTL, טיפוגרפיה, ריווח, כרטיסים מודרניים, צבעים רכים, מצבי כפתורים, וטוגלים אינטראקטיביים לשאלות הרגלים.
- `app.js` - לוגיקת האפליקציה: ניווט בין מסכים, שמירה/קריאה מ-`localStorage`, חישובי מגמות והרגלים, ניהול צ'אט דמה וסיכומי שיחה.

## איך להשתמש

1. לפתוח את `index.html` בדפדפן.
2. לבצע צ'ק-אין בוקר וערב.
3. לראות נתונים בדשבורד ובמסך ניתוח.
4. להשתמש בצ'אט תזונה ובצ'אט רווחה (כולל שמירת סיכום קצר בלבד בצ'אט רווחה).

## הרחבה עתידית (מוכן למשתמשים מרובים)

הלוגיקה מרוכזת ב-`state`, כך שניתן להוסיף מזהה משתמש כ-key ראשי בעתיד, ולהחזיק אובייקט נתונים נפרד לכל משתמש.
